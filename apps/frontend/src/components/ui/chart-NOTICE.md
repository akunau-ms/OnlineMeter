# Ported from shadcn/ui

`chart.tsx` in this directory is shadcn/ui's official chart primitive
(`ChartContainer`, `ChartConfig`, `ChartTooltip`, `ChartTooltipContent`,
`ChartLegend`, `ChartLegendContent`), copied unmodified from the shadcn/ui
registry (`ui.shadcn.com/r/styles/new-york/chart.json` — the same source
the `shadcn` CLI itself fetches from), per
`specs/004-chart-dark-theme-polish/research.md` decision 2.
